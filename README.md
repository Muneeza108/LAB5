# Lab Task 05 – Designing Specifications

## Objective

To apply method specifications, behavioral equivalence, preconditions, postconditions, mutation contracts, immutability, and declarative specifications using Java and JUnit.

## Implementation

* Implemented `findFirst()` and `findLast()` to demonstrate behavioral differences.
* Implemented gravitational potential energy with fail-fast precondition validation.
* Implemented mutable and non-mutating list operations.
* Demonstrated the risks of returning mutable `char[]` values and the safer use of immutable `String`.
* Compared operational and declarative JavaDoc specifications for `joinStrings()`.

## How to Run

1. Open the project in Apache NetBeans.
2. Build the project.
3. Right-click the project and select **Test**.
4. Verify that all JUnit tests pass.
